# Sales Performance Analysis Using Microsoft Excel

## Project Overview

This project analyzes sample sales data using Microsoft Excel to identify top-performing product categories and cities.

## Tools Used

* Microsoft Excel
* PivotTables and PivotCharts
* Excel formulas
* Dashboard visualization

## Key Performance Indicators (KPIs)

* **Total Sales:** ₹38,000
* **Average Sales per Order:** ₹4,750
* **Total Orders:** 8

## Key Findings

* **Electronics** generated the highest category sales at ₹25,000 (65.8%).
* **Clothing** generated ₹9,000 (23.7%).
* **Groceries** generated the lowest category sales at ₹4,000 (10.5%).
* **Guntur** had the highest city sales at ₹23,000 (60.5%).
* **Tenali** had the lowest city sales at ₹6,500 (17.1%).

## Workbook Contents

* `Sales_Data` — sample sales records
* `Category_Analysis` — sales by product category
* `City_Analysis` — sales by city
* `Dashboard` — KPI summary and charts

## How to Use

1. Download the Excel workbook from this repository.
2. Open it in Microsoft Excel.
3. Review the analysis sheets and dashboard.

## Limitations

This project uses a small practice dataset of eight sample orders. The findings describe sales revenue only and should not be treated as conclusions about profit, customer demand, or long-term trends.
